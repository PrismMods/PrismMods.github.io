# PrismMods.github.io

Landing page for [PrismMods](https://github.com/PrismMods) — mods for
*A Dance of Fire and Ice*.

Static HTML and CSS, no build step. Edit `index.html` to add or change a mod
card; each card sets its own `--gem` colour inline.

Served by GitHub Pages from `main` at the repository root.

## Local preview

```sh
python3 -m http.server 8000
```
