# Keybindings

| Key | Context | Action |
|-----|---------|--------|
| `Ctrl+E` | anywhere | Open settings |
| digits | no tool or selection | Pick a toolbar tool |
| digits | tile selected | Pick the nth event of the dock category; `Enter` stamps it |
| `,` / `.` | editor | Previous tool / saved slot (`Shift+.` saves the slot) |
| `Shift+K` | editor | Toggle quick chart mode (the toolbar's **Q** cell does the same) |
| `Shift+F` | editor | Toggle the Hz tool |
| `I` `O` `[` `]` | quick chart | Twirl / set speed / halve / double |
| `Shift+P` `Shift+L` `Shift+R` `Shift+O` `Shift+G` `U` | quick chart | Pause / location / move tile / hold / angle pad / edit |
| `A` `N` | editor | Autoplay pan / no-fail toggle |
| `Esc` | popups | Close the focused Sapphire popup |

The quick-chart and tool-slot rows are **defaults**: rebind them in `Ctrl+E` → **Keybinds**.

!!! note "Why these keys"
    The defaults avoid the editor's 17 tile-placement letters (`a b c d e h j m n q s t v w x y z`), which the game binds with **and** without `Shift` — so a bind on one of those steals tile placement.

See [Quick chart and angle pad](quick-chart.md) for the full quick-chart key list, and [Number fields](fields.md) for field shortcuts.
