# First steps

With Sapphire installed, open the level editor. Three controls are available everywhere.

- **The master switch.** The power button in the top-right corner gates the entire suite. Off means the vanilla editor.
- **Settings.** `Ctrl+E` opens the settings panel: the skin accent colour, feature toggles, keybinds and module options.
- **The manual.** The `?` button beside the active tool opens the in-editor instruction manual.

## The toolbar

An Adobe-style [toolbar](toolbar.md) replaces the event palette. When nothing is selected, the digit keys `1`–`0` pick the tools in the current category, and every cell has a hover tooltip.

## Charting from the keyboard

Press `Shift+K` (or the toolbar's **Q** cell) for [quick chart mode](quick-chart.md): twirls, speed changes, pauses and holds on single keys, plus the angle pad for typing whole runs of tiles.

## Seeing the song

The [event timeline](timeline.md) along the bottom puts every event on the song's time axis, with the waveform underneath. The **Audio** button beside the song offset opens the [Audio window](audio.md), which can find your BPM and offset.

## Key hints

A card in the bottom-right corner lists the keys that work in the current context. It rides above the event timeline, sizes itself to its content, collapses to a header, and can be turned off in `Ctrl+E` → **Features**. The full list is on the [Keybindings](keybindings.md) page.

## Testing your level

The **Edit / Play** chip above the timeline swaps between a clean charting screen and a playtest mirror. See [Edit and Play mode](playback.md).
