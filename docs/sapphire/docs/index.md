# Sapphire

Sapphire is an editor suite for **A Dance of Fire and Ice**. It adds a toolbar, an event timeline with camera keyframes, keyboard charting, audio analysis and other tools to the game's level editor.

[Install Sapphire](install.md){ .md-button .md-button--primary }
[First steps](first-steps.md){ .md-button }

!!! note "Alpha"
    Sapphire is in alpha. These pages are updated as features change.

## Compatibility

Sapphire writes ordinary level data. Level variables are saved as plain numbers, scripts compile into regular events, and multitracks are stored in an editor comment, so levels made with Sapphire play in the unmodded game.

## What's in it

### Charting

| Feature | What it does |
|---------|--------------|
| [Toolbar](toolbar.md) | An Adobe-style toolbar in place of the event palette: circular paths, free angles, pseudos, zips, VFX preview and more. |
| [Quick chart and angle pad](quick-chart.md) | Chart from the keyboard, and type whole runs of tiles as relative angles with math, twirls and repeats. |
| [Hz tool](hz-tool.md) | Chart by frequency: pick a pitch and get the angle, the BPM and the SetSpeed it needs. |
| [Shape library](shape-library.md) | A dockable palette of reusable shapes with live previews. |

### Timeline and audio

| Feature | What it does |
|---------|--------------|
| [Event timeline](timeline.md) | Events on a song-time axis, a camera keyframe workspace with eases, bezier curves and a graph editor, and the song's waveform. |
| [Audio window](audio.md) | Tempo curve, offset suggestions, a metronome on your level's grid, and a reading of every speed change in the chart. |

### Level editing

| Feature | What it does |
|---------|--------------|
| [Level settings and sidebars](level-settings.md) | A native level-settings panel, dockable sidebars, and a colour wheel for every colour value. |
| [Events](events.md) | Event tree selection, copy and paste, and the event tray. |
| [Decorations](decorations.md) | A decoration browser, and full editing for particle and object decorations. |
| [Level variables](variables.md) | Named values you can use in any number field. |
| [Script](script.md) | Runtime logic that compiles into ordinary events. |
| [Number fields](fields.md) | Arithmetic in every field, label scrubbing, and ranked search. |

### Interface

| Feature | What it does |
|---------|--------------|
| [Skin and panels](interface.md) | The dark reskin, floating windows, panel layout memory and on-screen key hints. |
| [Edit and Play mode](playback.md) | A clean charting screen and a playtest mirror, one chip apart. |
| [Experimental tools](experimental.md) | Patterns, retiming and multitracks, off by default. |
