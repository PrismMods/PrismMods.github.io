# Toolbar

An Adobe-style toolbar replaces the event palette. When nothing is selected, the digit keys `1`–`0` pick the tools under the current category, and each cell has a hover tooltip.

| Tool | What it does |
|------|--------------|
| **Circular path** | Build arcs, circles and stars as midspin sequences. |
| **Free angle** | Free-rotate a tile by dragging. Hold **Left Alt** or arm the tool; right-click stays free for the tile menu. |
| **Pseudo (동타)** | Turn a tile into a beat-neutral pseudo, with a single click or as a multi-select batch, with midspin and twirl constructions and retune. |
| **Camera path** | An on-screen FreeCamera path overlay: click keyframes to inspect them, ▶ to preview, and play all with beat gaps. |
| **Zip** | Replace a tile with a zip: 360° in total, split evenly across N keys (at least 4). |
| **VFX preview** | VFX-only mode. Hides all UI, the game's included, so you can preview visuals. It persists into play mode; `Esc` exits. |
| **Inspector** | An eyedropper. Left-click captures a tile's events, right-click pastes them onto tiles. The copy panel also works as a paste filter. |
| **Quick chart (Q)** | Toggle fast in-place charting. See [Quick chart and angle pad](quick-chart.md). |
| **Shape library** | A dockable palette of reusable shapes. See [Shape library](shape-library.md). |
| **Hz tool (♪)** | Chart by frequency, with a note picker. See [Hz tool](hz-tool.md). |

`,` and `.` step to the previous tool and to a saved slot; `Shift+.` saves the slot. Both are rebindable in `Ctrl+E` → **Keybinds**.

## Other tools

- **Selective copy and mirror** — with several tiles selected, a panel in the top-right corner copies them and mirrors their geometry.
- **Filter browser** — the game's roughly 300-entry `SetFilterAdvanced` dropdown, as a searchable, category-organised browser. Its chip rides the game's event panel.
- **Event presets** — save named bundles of events through the Inspector, and stamp them back onto tiles.
