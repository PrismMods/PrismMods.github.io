# Input

## Key limiter

Only the keys you allow count as gameplay input. On by default.

- **Use key viewer keys** (default) — the allowed keys are the ones in your active hand and foot key viewer presets.
- **Custom keys** — or type your own list, separated by spaces or commas.

## Chatter blocker

A worn or bouncy switch can send two presses for one. The chatter blocker drops a press that lands within the threshold of the same key's previous accepted press. Off by default; the threshold starts at **50 ms**.

## Input while the menu is open

**Block inputs while menu open** (on by default) stops the game from seeing any keyboard input while the Topaz menu is open, so typing in a field or pressing a key to rebind doesn't also play the level or navigate the game's menus. The key viewer keeps showing presses either way.
