# Bismuth

Bismuth is an overlay and quality-of-life mod for **A Dance of Fire and Ice**, and the lite version of [Quartz](https://quartzz.xyz/). It includes in-game stats, a key viewer, custom fonts and a few fixes. Most settings can be adjusted in detail.

[Install Bismuth](install.md){ .md-button .md-button--primary }

## Opening the settings

Press `Ctrl+B` in-game to open the settings panel. The toggle at the bottom of its tab rail is the master switch: off, Bismuth stops changing the game but the panel stays available.

## Features

| Feature | What it does |
|---------|--------------|
| [Overlay](overlay.md) | Stats in-game — progress, accuracy, X-accuracy, BPM, tile BPM, KPS, timing scale, judgements, combo, attempts and FPS. |
| [Key viewer](key-viewer.md) | Hand and foot key viewers with key rain, ghost keys, press counts and DM Note presets. |
| [Fonts](fonts.md) | Your own fonts for the overlay, the settings panel and the game's own text. |
| [Game UI](game-ui.md) | Move, scale, hide or re-weight the game's HUD elements, and hide UI you don't want. |
| [Input](input.md) | Key limiter, chatter blocker, and an input block while the menu is open. |
| [Troubleshooting](troubleshooting.md) | Logs, the in-game log viewer, and fixing a double install. |
