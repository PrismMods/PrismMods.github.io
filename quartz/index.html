Quartz

An all-in-one mod for A Dance of Fire and Ice.

Stable Gameplay

Quartz adds overlays, input tools, calibration, a TUF level browser and Discord to the game. Each feature is a separate module that can be installed or removed.

TUF

Modules

Features are installed, updated, turned off or removed from the Modules tab in-game.

Overlays

Key viewer, combo, judgements, progress bar and custom stat panels. Reorganize mode moves them by dragging.

TUF levels

Browse, download and play TUF levels and packs inside the game.

Other features

  • Calibration Sets the input offset from play, with timing history per map.
  • Too Much Accuracy Per-hit accuracy with a custom curve, death markers and an exportable run log.
  • Practice difficulty Keys that switch difficulty and pitch mid-level.
  • Key limiter Limits input to chosen keys and filters key chatter.
  • Profiles Separate settings profiles, shareable as files.
  • Discord Messages and voice chat in-game.
  • Effect remover Removes level effects, in Simple or Enhanced mode.
  • Addons Community addons with their own settings, panels and text tags.
  • Optimizer GC timing, process priority, bloom and other performance options.

Install

Quartz has its own site and docs at quartzz.xyz. It runs on MelonLoader (recommended) or UnityModManager.
