Docking

Windows dock into the sidebars as tabs and can be pulled back out. The layout can be kept between sessions.

Quick charting

Twirls, speed changes, pauses and holds are bound to single keys. The angle pad places runs of tiles from relative angles, with a preview.

Event timeline

Events are shown on the song's time axis. Cam mode adds position, rotation and zoom lanes, eases, bezier curves and a graph editor for MoveCamera.

Variables and Script

Number fields accept formulas like $beat*2 that update with the variables. Scripts compile into regular events.

Shape library

Reusable shapes in a dockable palette, with a preview for each key count. Shapes can be saved from the angle pad or from selected tiles.

Other features

  • Hz tool Charting by frequency. Calculates the angle, BPM and SetSpeed for a pitch.
  • Audio window Tempo curve, offset suggestions and a metronome on the level's grid.
  • Toolbar Circular path, free angle, pseudo, zip, VFX preview and an event eyedropper.
  • Event tray A visible clipboard for events. Drag events in and out.
  • Filter browser Searchable list of SetFilterAdvanced filters, by category.
  • Decorations Decoration list by tag or thumbnail. Full editing for particles and objects.
  • Edit and Play mode Switches between a charting view and a playtest view.
  • Number fields Arithmetic in fields, drag-to-scrub labels and ranked search.
  • Colour wheel HSV colour picker for all colour values.

Install

Alpha. Runs on UnityModManager, or on MelonLoader with UMMCompat.
