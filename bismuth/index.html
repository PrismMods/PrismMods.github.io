Bismuth

A lighter version of Quartz with overlays and basic tools.

Stable Gameplay, lite

Bismuth is the lite version of Quartz: in-game stats, a key viewer, custom fonts and a few fixes. Most settings can be adjusted in detail.

Overlay

Progress, accuracy, X-accuracy, BPM, timing scale, judgements, combo and attempts. Each can be turned on or off, positioned and coloured.

Key viewer

Hand and foot presets, key rain, ghost keys and saved press counts. Imports and exports DM Note presets.

Game UI

The game's own HUD elements can be moved, scaled or hidden, and its text can use a custom font.

Other features

  • Key limiter Only selected keys count as input.
  • Chatter blocker Ignores repeat presses that come too quickly.
  • Custom fonts Font packs or your own .ttf and .otf files, for the overlay and game text.
  • Hide UI Hides the HUD, hit error meter, autoplay text, judgements, song title and more.
  • Attempts Attempt counts per level, saved between sessions.
  • DM Note presets Imports and exports DM Note key viewer presets.
  • Log viewer and reload In-game log viewer and one-click reload.
  • Updates Checks for new releases and installs them.

Install

Requires A Dance of Fire and Ice 3.3.0 or later. Runs on UnityModManager, or on MelonLoader with UMMCompat.
